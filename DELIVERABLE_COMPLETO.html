Visão Geral

BEAST MARAGAMES é uma plataforma mobile educacional para participação em eventos de arenas de jogos. O sistema permite que participantes se registrem, entrem em eventos através de QR Code ou código manual, registrem experiências, e recebam feedback em tempo real.

Objetivos Principais

  • Simplificar entrada em eventos (QR Code com fallback)
  • Rastrear participação e experiências em tempo real
  • Criar histórico personalizado por participante
  • Facilitar coleta de feedback após eventos
  • Oferecer interface intuitiva e responsiva

Princípios de Design

🎯 Simplicidade

Interface limpa, sem ruído visual. Cada tela tem um objetivo claro.

💎 Valor ao Participante

Histórico, progresso e reconhecimento das atividades realizadas.

⚡ Zero Fricção

Entrada rápida, fluxo intuitivo, mínimo de digitação.

🎯 Análise de Decisões Estratégicas

Decisão #1: Como participantes entram em eventos?

Opção A: QR Code (Scanning)

✅ Velocidade: Escaneia e entra em segundos

✅ UX Moderno: Padrão em eventos

❌ Falha: Câmera pode não funcionar, QR danificado

❌ Dependência: Precisa de QR físico

Opção B: Código Manual (Digitação)

✅ Robustez: Funciona sem câmera

✅ Fallback: Sempre disponível

❌ Lentidão: Digitação é chata

❌ Erros: Código digitado errado

Opção C: Ambos (Híbrido) ⭐ RECOMENDADO

✅ Velocidade: QR Code primário (rápido)

✅ Robustez: Código fallback (seguro)

✅ UX: Melhor dos dois mundos

✅ Recomendação: Implementar entrada HÍBRIDA (QR Code primário + Código manual como fallback)

Decisão #2: Como rastrear experiências durante o evento?

Opção A: Entry/Exit Apenas

✅ Simplicidade: Mínimas dados

❌ Valor: Sem detalhes sobre o que foi feito

Opção B: QR por Estação

✅ Detalhe: Sabe exatamente o que participou

✅ Engajamento: Timer em tempo real

✅ Dados: Melhor qualidade de dados

❌ Complexidade: Requer QR em cada estação

✅ Recomendação: QR Code por estação de experiência (detalhe + qualidade de dados)

Decisão #3: O que mostrar como benefício ao participante?

Opção A: Histórico Apenas

✅ Simples: Lista de eventos passados

❌ Engajamento: Baixa motivação repetida

Opção B: Histórico + Progresso Leve

✅ Engajamento: Mostra progresso (horas, eventos)

✅ Simplicidade: Sem gamificação complexa

✅ Motivação: Incentiva participação repetida

✅ Recomendação: Histórico + Progresso Leve (horas totais, número de eventos, experiências realizadas)

Navegação de Abas (Sempre Visível)

Bottom Tab Navigation

Aba 1: 🏠 Início - Home principal, saudação, card de entrada

Aba 2: 📍 Eventos - Meus eventos, histórico, detalhes

Aba 3: 👤 Perfil - Dados pessoais, preferências, logout

🔄 Fluxos de Navegação Principais

Fluxo 1: Primeiro Acesso (Novo Participante)

1. Boas-vindas

Apresentação do app + Logo BEAST

2. Criar Conta

Nome, E-mail, Senha (com validação)

3. Questionário de Perfil

4 perguntas (Idade, Gaming, Gêneros, Confirmação)

4. Home

Primeira vez sem histórico - pronto para participar!

Fluxo 2: Entrar em Evento

1. Home → Entrar em Evento

Click no card principal

2. Opção A: Escanear QR

Câmera abre, escaneia QR do evento

2. Opção B: Digitar Código (Fallback)

Se QR falhar, digita código manual

3. Confirmação

Mostra evento, local, experiências disponíveis

4. Confirmar Entrada

Timer começa, agora em "Evento Ativo"

Fluxo 3: Participar e Registrar Experiências

1. Evento em Andamento

Timer rodando, lista de experiências

2. Ir para Estação de Experiência

Ex: PlayStation, VR Reality, Simulador

3. Registrar Experiência

Click em "Registrar" → Escaneia QR da estação

4. Experiência Salva

Marca como ✅ com timestamp

5. Sair da Arena

Vai para Resumo & Avaliação

Fluxo 4: Avaliação e Histórico

1. Resumo do Evento

Tempo total, experiências realizadas

2. Avaliar Experiência

Click em estrelas (1-5), comentário opcional

3. Enviar Avaliação

Salva no histórico

4. Volta à Home

Evento aparece em "Meus Eventos" na aba 2

🎨 Padrões de Design

Identidade Visual

🎨 Cores Principais

Roxo Primário: #8B4789 (CTA, seleção, destaques)

Vermelho Secundário: #C41E3A (Gradientes, ênfase)

Branco Base: #FFFFFF (Fundo, cards)

Neutro: #333333 (Texto), #666666 (Secundário), #999999 (Terciário)

Componentes Principais

1. Bottom Tab Navigation

Sempre visível, 3 abas (Início, Eventos, Perfil). Tab ativa tem linha roxa no topo.

2. Cards de Evento

Gradiente roxo-vermelho, branco para texto, ícones de emoji para categoria.

3. Botões CTA

Primário: Gradiente roxo-vermelho, uppercase, font-weight 600

Secundário: Fundo cinza claro, texto escuro

4. Campos de Input

Borda cinza 1px, border-radius 8px, focus com borda roxa

Tipografia

Fonte: System fonts (-apple-system, Segoe UI, Roboto)

H1/Títulos: 24px-32px, weight 700, cor #333

Corpo: 14px-16px, weight 400, line-height 1.6

Labels/Pequeno: 12px-13px, weight 600, cor #666

Espaçamento

Padding Cards: 16px-24px

Margin Between Sections: 24px

Border Radius: 8px (padrão), 12px-16px (cards grandes)

Estados de Erro

❌ Câmera não disponível

Mensagem clara + opção de digitar código manual

❌ Sem internet

Mensagem + opção de tentar novamente ou usar código

❌ Já registrado neste evento

Aviso de duplicate + opção de continuar ou sair
